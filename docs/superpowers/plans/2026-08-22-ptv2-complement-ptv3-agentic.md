# PTV2 Complement and PTV3 Agentic Dataset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build immutable, target-specific B/C/D speculative-drafter corpora and training/evaluation gates that compare equal assistant-loss-token exposure without contaminating the prior 1.3M corpus or held-out evaluations.

**Architecture:** Extend the existing `examples/dataset` inventory and selection tools with one typed canonical-record contract shared by audit, synthesis, replay, tokenization, quota selection, and publication. Keep corpus publication, cross-cluster receipts, training identity/adoption, and evaluator decisions as separate fail-closed boundaries, while reusing the existing Qwen4B study launcher and content-addressed transfer framework. Every durable identity is derived from canonical JSON and SHA-256, and every state transition is validated before the next CPU, GPU, transfer, training, or replacement action.

**Tech Stack:** Python 3.12+, dataclasses and `TypedDict`, Hugging Face `transformers`, PyArrow/Parquet Zstd, YAML, PyTorch/Hugging Face Trainer, Bash/Slurm/Pyxis, PDX/PBSS `rclone`, pytest, Pyright, Ruff, pre-commit, ShellCheck.

**Spec:** `docs/superpowers/specs/2026-08-22-ptv2-complement-ptv3-agentic-design.md`

## Global Constraints

- The prior 1.3M corpus is lineage and an exclusion set; it retains its existing dataset and experiment identities and is never relabelled as B.
- The prior audit must resolve exactly 26 symlinked shards and reconstruct exactly 1,300,000 rows: chat 627,720; code 175,000; math 239,467; multilingual_de 257,813; all other specified splits zero.
- The raw PTV2 source revision is exactly `5c89e01dd720ae0f4058445ed49c5fb68a03c76e`; every source also pins license, physical file path, byte size, and SHA-256.
- Canonical prompt UUIDs are SHA-256 digests of normalized prompt-bearing conversations that preserve roles, content, top-level tools, tool-call structure, and message order while removing storage-only fields and using deterministic JSON.
- Deduplication against the audited prior corpus, held-out SPEED/Math/Code/SWE/tool UUIDs, and already admitted candidates occurs before quota selection; different canonical bytes under one UUID are fatal.
- All mixture weights, quotas, gates, and exposure counts are assistant-loss tokens from the pinned target tokenizer and training mask, never rows, bytes, prompts, total context tokens, padding, or masked tokens.
- B uses only unused PTV2 prompts, excludes `multilingual_de`, and uses exact Math/Code/STEM/Chat/Multilingual weights `25/25/20/20/10`; its source completions are stripped and regenerated by the exact target.
- C and D use exact top-level SWE/Math/Code/STEM/Chat/Multilingual weights `35/25/15/15/5/5`; C's SWE quota is 35% agentless target synthesis, while D uses 15% agentless synthesis, 10% interactive SWE replay, and 10% generic tool replay.
- Candidate ordering hashes dataset identity, category, context bucket, source ID, and prompt UUID with the pinned seed; no lexical prefix selection, row cap before shuffle, silent source ratio, or quota renormalization is permitted.
- Qwen3-4B, Qwen3-30B-A3B, and Qwen3-235B-A22B responses are independent synthesis families; thinking-on and thinking-off use identical selected synthesis UUIDs but distinct uniform manifests and namespaces.
- Replay is recorded source-native behavior: it preserves tools, tool calls, call IDs, results, message order, and reasoning, and never claims target execution or manufactures a thinking mode.
- Full validated context is retained through 32K and bucketed `le4k`, `4k_16k`, or `16k_32k`; the separate 4096-token view is derived, and a view splitting a tool transaction is excluded from 4K training.
- Dataset identity is `ptv23-complement-v1-<target>-<thinking>-<arm>-<selection_sha256_12>`; source/revision/seed/tokenizer/template/candidate/target/mode/token-ID/mask changes create a new identity.
- Publication uses a job-unique sibling partial directory, validates and `fsync`s every file and directory, and atomically renames into a previously absent immutable namespace; it never overwrites a final namespace.
- B, C, and D use identical initialization, optimizer, learning-rate schedule, seed, effective batch, sequence length, method, block size, target serving configuration, and cumulative exposure gates `256000000`, `1000000000`, and `4000000000`.
- Weight adoption validates model/drafter name, shape, dtype, and hash, but resets optimizer, scheduler, scaler, RNG, loader cursor, epoch, global step, and W&B resume ID; it records the parent checkpoint as lineage at step zero.
- D advances only if it improves held-out SWE/agentic acceptance over C without reducing a major Math or SPEED category by more than 3%; C or D must improve held-out SWE acceptance over B by at least 10%.
- Correctness mismatch against the target's deterministic tolerance is a stop condition; it cannot be traded for speed.
- One canonical cluster builds each corpus; PDX/PBSS transfers use content-addressed prefixes and verified receipts, bulk transfer never runs on a login node, and credentials never appear in arguments, manifests, logs, or Git.
- The pending `s25391` replacement remains ineligible until immutable corpus, exclusion, quota/schema, destination receipt, evaluator readiness, and training-canary gates all pass; this plan does not authorize job cancellation, submission, or replacement.
- Before submission, formatting, lint, type checking, focused tests, manifest dry runs, and `sbatch --test-only` must pass; a bounded synthesis and training canary must then produce valid shards, a complete checkpoint, per-GPU telemetry, and evaluator output.

def audit_baseline(root: Path, expected: BaselineExpectation) -> BaselineAudit:
    links = sorted(path for path in root.iterdir() if path.is_symlink())
    if len(links) != expected.shard_count:
        raise AuditError(f"shard count mismatch: {len(links)}")
    files = tuple(hash_resolved_shard(link) for link in links)

    return BaselineAudit.from_rows(expected, files, rows)
